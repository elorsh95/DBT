סטודיו אנימציה לקלוד
====================

מה זה?
סקיל שהופך את קלוד לסטודיו אנימציה. מבקשים אנימציה, בוחרים סגנון מתוך 10
(או מתארים סגנון משלכם), מאשרים את רשימת הסצנות, וקלוד בונה את האנימציה בקוד,
בודק אותה בעצמו ומוציא קובץ MP4, ואם רוצים גם GIF.
כל הטקסט על המסך בעברית, מימין לשמאל.

מה צריך?
* Claude Code או Cowork.
* מודל Claude Opus 5.5 ומעלה. במודל חלש יותר התנועה יוצאת נוקשה.
* בפעם הראשונה קלוד מתקין לבד את הכלים שהוא צריך (Python, דפדפן שמצלם
  את הפריימים ו-ffmpeg). אתם רק מאשרים. זה לוקח כמה דקות, פעם אחת.

איך מתקינים?
1. חלצו את קובץ ה-zip (קליק ימני > Extract All / פתיחה).
2. פתחו את Claude Code ותגידו לו:
   תתקין את הסקיל מהתיקייה הזאת: <הנתיב לתיקייה motion-studio>
3. סגרו ופתחו מחדש את Claude Code.

משתמשים ב-Cowork? ב-claude.ai נכנסים ל-Settings > Skills ומעלים את קובץ ה-zip.

רוצים להתקין ידנית? מעתיקים את התיקייה motion-studio לתיקיית הסקילים:
   במק:      /Users/<שם המשתמש>/.claude/skills
   בווינדוס: C:\Users\<שם המשתמש>\.claude\skills
   (אם התיקייה skills לא קיימת, יוצרים אותה)

איך משתמשים?
כותבים לקלוד "תיצור לי אנימציה". הוא ישאל באיזה סגנון, ישאל כמה שאלות על
הטקסט והצבעים, יראה לכם את התוכנית, ורק אחרי שתאשרו יתחיל לבנות.

מוזיקה
הסקיל לא מגיע עם שירים. רוצים מוזיקה? מורידים שיר מ-Mixkit (mixkit.co,
חינם גם לשימוש מסחרי) ונותנים לקלוד את הקובץ. בלי שיר, קלוד מייצר אפקטים
קוליים בעצמו.

הפונטים בתיקייה הם Google Fonts ברישיון OFL. הפרטים ב-assets/fonts/OFL.txt.
