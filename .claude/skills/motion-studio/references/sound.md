# סאונד

## החוקים

- **אין קבצי סאונד בסקיל.** כל אפקט מסונתז ב-numpy בתוך `audio.py`, ברגע הרינדור.
- **מוזיקה רק מהמשתמש.** הסקיל לא מוריד שירים. המשתמש מביא קובץ שמותר לו להשתמש בו. ההמלצה: Mixkit (mixkit.co), שהרישיון החינמי שלו מתיר שימוש מסחרי בלי קרדיט. שירים מסטרימינג או מיוטיוב אסורים לשימוש.
- המאסטר יוצא ב-`-14 LUFS` (הרמה של רשתות חברתיות), עם שיא של `-1 dBTP` לכל היותר.

## ברירת מחדל: אפקטים בלבד

בזמן הבנייה של הסצנה קוראים ל-`sfx(t, kind, gain)`. הזמן הוא הרגע שבו התמונה קורית (החבטה מתחילה, הכפתור נלחץ), לא לפניו.

| סוג | צליל | מתי |
|---|---|---|
| `click` | קליק ממשק | לחיצה של סמן, מתג |
| `tick` | טיק קטן | שינוי קטן, מעבר בין מצבים |
| `count` | טיק זעיר | מונה מספרים, כמה ברצף |
| `key` | מקש | כל תו בהקלדה (gain 0.5) |
| `pop` / `popHi` | פופ | אלמנט שקופץ פנימה, בועה |
| `hit` | חבטה קצרה | מילה נחבטת, חיתוך על הביט |
| `impact` | מכה גדולה | רגע שיא אחד או שניים |
| `sub` | בום עמוק | פעם אחת לכל היותר בכל סצנה |
| `thud` | חבטה רכה | נחיתה, כדור שפוגע |
| `whoosh` / `swish` | אוויר | מעבר גדול. **לכל היותר פעם אחת בסצנה**, ושקטים יותר מהמכות במכוון |
| `rise` | עלייה | בנייה לפני רגע שיא |
| `ding` / `chime` / `success` | צלצול | הצלחה, הודעה, סיום |
| `sparkle` | נצנוץ | חשיפה של לוגו או מילה |
| `glitch` | גליץ' | שבירה דיגיטלית |
| `shutter` | צילום | תמונה נלכדת, בחירה ננעלת |
| `boing` | קפיץ | דמות קופצת, קריקטורה |

- 2 עד 6 אפקטים בכל סצנה, רק על רגעי שיא. סאונד על כל תנועה נשמע כמו משחק ילדים.
- `gain` בין 0.3 ל-1 מדרג אפקטים מאותו סוג (הראשון חזק, השאר שקטים יותר).
- לשמוע את כל הסוגים ברצף: `"$PY" audio.py demo` יוצר `out/sfx-demo.wav`.
- סוג חדש: מוסיפים ענף ב-`make()` ורמה ב-`LEVEL` בתוך `audio.py`.

## עם שיר של המשתמש

1. המשתמש שם את הקובץ בתיקיית הפרויקט (או נותן נתיב, ואז מעתיקים אותו לשם).
2. מודדים את הקצב:
   ```bash
   "$PY" audio.py beat music.mp3
   ```
   הפלט: BPM, הביט הראשון, והתיבה הראשונה (downbeat).
3. ב-`CONFIG`:
   ```js
   bpm: 120, beat0: 0,
   music: { file: 'music.mp3', start: 13.357, gain: 0 },
   ```
   `start` הוא downbeat מתוך השיר (הרגע שבו האנימציה מתחילה). `beat0: 0` כי הסרטון מתחיל בדיוק עליו. `gain` בדציבלים.
4. בסצנה משתמשים ב-`beat(n)` לכל תזמון, ו-`sfx(beat(n), 'click')` לצלילי ממשק.
5. `audio.py` מזיז כל אפקט עד 25 מילישניות אל הפיק הקרוב בשיר, כך שהוא יושב על הביט שנמדד. `snap: false` ב-CONFIG מבטל את זה.

האורך: `DUR` כדאי שיהיה מספר שלם של תיבות (בקצב 120, תיבה היא 2 שניות). בלופ זה חובה.

## כמה חזק

`LEVEL` ב-`audio.py` קובע כל סוג ביחס לעוצמה של השיר (או לרמת ייחוס קבועה כשאין שיר). אם משהו בולט מדי, משנים את ה-gain של הקריאה, לא את LEVEL.
